# Runtime Distribution

zzz engines and probes will be distributed as compiled binaries. This directory
will hold the metadata for downloading them. Release archives will be published
as release assets rather than committed to the source tree.

> **Note**: Downloads are not available yet. For now, use a runtime bundle or
> supplied binaries — see [Installation](../docs/installation.md#runtime-bundle).

## Planned

- A release index listing versions, platforms, compatibility, download locations,
  and artifact hashes
- An index schema and public signature-verification keys
- Download, verification, and installation from within zzzbench
- License terms shipped with each binary bundle

No placeholder index, key, or download URL is provided until these exist. Build
credentials and signing secrets never belong here.
